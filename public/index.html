Informações sobre o sistema AquaLevel

AQUALEVEL

Automação e Controle Inteligente de Reservatórios de Água

O AquaLevel é um sistema embarcado inteligente desenvolvido para monitorar e controlar automaticamente o nível de água em reservatórios.

ESP32 Microcontrolador responsável pelo processamento e comunicação Wi-Fi.
HC-SR04 Sensor ultrassônico utilizado para monitoramento do nível da água.
Controle automático Aciona e desliga a bomba conforme os limites configurados.
Dashboard Web Permite acompanhar nível, bomba, alertas e histórico.
